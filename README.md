## Adding stops (no presets)
After a trip starts, nothing is pre-filled: the customer types a store or address.
- Autocomplete starts after 3 letters (300 ms debounce). With `MAPS_API_KEY` set in `js/config.js` it uses Google Places (New) `AutocompleteSuggestion` with session tokens, biased to Great Neck. Without a key, or if the key fails (`gm_authFailure`), it uses a built-in Great Neck / Nassau dataset (`js/places.js`) with fuzzy prefix matching.
- Store results open a DoorDash-style store browser (`js/addstop.js`): sticky category tabs, search across the whole catalog, + buttons and quantity steppers, custom items, and a per-stop cart. The cart ("Add to trip · $X") sets the stop's items and the upfront price (service fee + spending cap, which is goods × 1.2 rounded up to $5).
- Personal places (homes, addresses) skip the browser and go to Pick up / Drop off / Other task.

## Catalog provider (`js/catalog.js`)
`Catalog.setProvider(p)`, where `p` implements async `getStore(kind, place)`, `getCategories(storeId)`, `getItems(storeId, category)` and `searchItems(storeId, query)`.
Items: `{id, name, price, category, image, icon, unit, inStock}`. The bundled SampleProvider ships illustrative menus. Swap in a real backend or partner API without touching the UI.

## Google Cloud console (for the live site)
- Enable the **Geocoding API**: it's used only when a customer picks a typed address ("Use “…”"). Without it the app falls back to "Address as typed" and logs one console error.
- Optional: set `MAPS_MAP_ID` in `js/config.js` to use Advanced Markers. This removes the `google.maps.Marker` deprecation warning.
- Directions (Legacy) doesn't need enabling. Routes API is primary, and straight lines are the last fallback.

## Pricing (engine v4, Adam, from finance/pricing_v4)
- `js/pricing.js` is generated by `python3 tools/build_pricing.py`. It holds engine.js verbatim, wrapped in an IIFE as `PricingEngine`. Do not edit it by hand. `node --test tests/` checks every test vector to the cent and verifies the engine hash.
- `quote()` in js/data.js maps the stops to engine inputs. Groceries→grocery (items = total quantity), Pharmacy→pharmacy, Returns→return, Post office→post_office, and everything else→pickup. `basket_per_stop` = goods ÷ stops. All other inputs use the spec defaults.
- While the customer edits, miles come from the straight-line solver and the price is labeled "est.". On Review, Google Routes (called once per final route and cached) supplies road miles and drive time. Time is passed as `mph = miles ÷ hours`, and the price locks.
- The old base/per-stop/per-mile fees, Rush, Plus membership discount and bundles were removed.
- PROTOTYPE: the price is calculated on the client for display only.
